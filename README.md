# Video Analyst App

A project to build a web-based video analysis app inspired by ViperGPT (https://arxiv.org/pdf/2303.08128): A visual reasoning approach that uses an LLM to generate a visual program that can be executed by an API layer, calling various vision models to perform the analysis in a modular fashion.  The app will be powered by Azure on the backend to support live API calls to the coding llm as well as various vision models.

The project should start small and build incrementally to support solid understanding and good design choices at each stage.
